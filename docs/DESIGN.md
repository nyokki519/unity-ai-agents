# 運営データ表示の基準

利用者の優先事項: 見やすさ、分かりやすさ、iPhoneでの日常利用。既存の深緑/淡い背景を再利用する。

1. 最初に全体の状態、観測日時、主要3指標、次の確認を示す。
2. 主要値は数値カード。桁区切りと既知/対象イベント数を添える。nullは未取得、0は実測。
3. AIは未検証の別領域。古い/不一致データを現在の成果と見せない。
4. 長い比較・診断・実行情報はnative detailsで展開し、初期画面を長くしすぎない。警告の状態は要約にも残す。
5. 色に加えて文字で意味を伝える。44px以上の操作領域、focus表示、文書順序を保つ。
6. 390px/1280pxで確認。実データの認証画面を見られないときは模擬データであることを明記する。

2026-10-22のローカル画面確認: 以前は主要値が長い段落に埋まり、複数カードで確認事項が重複していた。現構成は数値カードと詳細展開を採用。専用ブラウザは使えず、ローカルChromiumの模擬画面で確認。ライブUI/全面的なアクセシビリティ準拠の検証ではない。`DESIGN_CAPTURE_DIR=/tmp/unity-design python scripts/daily-ui-smoke.py`で模擬データの画面と検証を再現できる。
