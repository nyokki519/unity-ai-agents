# Phase 0〜1 の実装設計

ユーザーの「安全な初期値でPhase 0〜1を実装」を優先し、承認待ちで通常のローカル開発を止めず進める。新しい独立ローカルrepoだけを変更する。

1. 無料条件を公式GitHub資料とCodex READMEで確認し、根拠未確認のサービスを不採用とする。
2. ローカルJSONの原子的保存、schema、queue、役割登録、保守的な権限分類、手動引継ぎを実装する。
3. 期限/対象/単回承認と緊急停止を先に検証し、危険操作の実行器は入れない。
4. Node標準HTTPと静的UIで認証付きの8画面、CLIを追加する。
5. unit/HTTP/ブラウザで実動確認し、導入待ちと未実装を記録する。

Phase 1成功条件: 既存repoを変更せず起動でき、認証なしでは操作不可。ローカル集計が完了し、AI依頼は保留+構造化promptになる。重要操作は実行されず、再試行と重複防止と停止が永続化される。追加月額0円、外部API/AI呼び出し0。
